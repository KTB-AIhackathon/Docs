**기능명세서 (상세)**

### 1. 문서 개요

- **서비스명**: (가칭) DevFlow Agent / Portfolio Agent
- **목적**: GitHub + Notion 데이터를 기반으로 개인·팀의 일정·진행상황·포트폴리오를 자동으로 관리하고 지속적으로 개선하는 멀티유저 AI 에이전트 서비스
- **핵심 가치**: 사용자 대신 작업을 수행하는 에이전트 자동화 + 개인/팀 모두 사용 가능 + 포트폴리오 확장성
- **기술 스택 기준**: Spring Boot (백엔드·인증·비즈니스) + FastAPI + LangGraph (에이전트 오케스트레이션) + GitHub MCP + Notion MCP

---

### 2. 사용자 유형

| 유형 | 설명 |
| --- | --- |
| 개인 사용자 | 자신의 GitHub 레포 + Notion을 연결하여 개인 일정·진행·포트폴리오를 관리 |
| 팀 리더 | 그룹 생성 후 팀원 초대, 공유 프로젝트 관리 |
| 팀원 | 그룹에 참여하여 공유 일정·진행상황을 함께 사용 |
| 관리자 | 시스템 운영 (추후) |

---

### 3. 주요 기능 대분류

1. 사용자 인증 및 프로필 관리
2. 외부 연동 (GitHub / Notion)
3. 개인 자동화 기능
4. 친구·그룹(팀) 기능
5. 팀 프로젝트·일정 관리
6. 포트폴리오 자동 생성·관리
7. 에이전트 자동화·스케줄링
8. 알림 및 대시보드

### 4. 상세 기능 명세

#### 4.1 사용자 인증 및 프로필 관리

- **기능 ID**: AUTH-001 ~ AUTH-004
- **설명**
    - 회원가입 / 로그인 (이메일 또는 GitHub OAuth)
    - JWT 기반 인증
    - 사용자 프로필 조회·수정 (이름, 소개, 아바타 등)
    - 사용자 ID 기준 고유 식별
- **주요 처리**
    - 로그인 성공 시 Access Token + Refresh Token 발급
    - 프로필에 GitHub / Notion 연결 상태 표시

#### 4.2 외부 연동 (GitHub / Notion)

- **기능 ID**: INTEG-001 ~ INTEG-006
- **설명**
    - GitHub Personal Access Token 또는 OAuth 연결
    - Notion OAuth 연결 (공식 MCP: `https://mcp.notion.com/mcp`)
    - 연결 상태 조회 및 해제
    - 유저별 토큰 암호화 저장
- **주요 처리**
    - GitHub: 레포 목록, 커밋, 이슈, PR, 파일 내용 조회/수정 권한
    - Notion: 페이지·데이터베이스 생성/조회/업데이트 권한
    - 토큰은 유저별로 완전히 격리

#### 4.3 개인 자동화 기능

- **기능 ID**: PERS-001 ~ PERS-005
- **설명**
    - 내 GitHub 레포 기반 진행상황 자동 수집
    - Notion에 자동 메모·진행 로그 작성
    - 일정(마감일, 마일스톤)과 실제 진행률 자동 비교
    - 오래된 README 감지 및 개선 제안/자동 수정
- **주요 처리 흐름**
    1. GitHub MCP로 최근 커밋·이슈·PR 조회
    2. 변화 감지
    3. Notion MCP로 해당 프로젝트 페이지에 진행 메모 자동 추가/업데이트
    4. 필요 시 README 개선안 생성 후 PR 또는 직접 반영

#### 4.4 친구·그룹(팀) 기능

- **기능 ID**: TEAM-001 ~ TEAM-007
- **설명**
    - 사용자 ID 기준 친구 추가 / 수락 / 삭제
    - 그룹(팀) 생성
    - 그룹에 친구 초대
    - 그룹 멤버 목록·권한 관리 (리더 / 멤버)
- **주요 처리**
    - 친구 관계는 양방향 또는 단방향 선택 가능
    - 그룹 생성 시 기본 Notion 공유 페이지/DB 자동 생성 옵션
    - 그룹에 GitHub 레포 연결 가능

#### 4.5 팀 프로젝트·일정 관리

- **기능 ID**: PROJ-001 ~ PROJ-006
- **설명**
    - 그룹 내 프로젝트 생성
    - 일정(마감일, 스프린트) 등록
    - 실제 진행상황 자동 반영 (GitHub 커밋/이슈 기반)
    - 팀원별 기여도·진행률 요약
    - Notion 공유 보드에 자동 업데이트
- **주요 처리**
    - GitHub 이벤트 → Notion DB 행 업데이트
    - 일정 대비 실제 진행률 계산 후 경고/알림

#### 4.6 포트폴리오 자동 생성·관리

- **기능 ID**: PORT-001 ~ PORT-005
- **설명**
    - 개인/팀 프로젝트를 기반으로 포트폴리오 카드 자동 생성
    - 기술 스택·기여도·주요 성과 자동 추출
    - 포트폴리오 페이지 미리보기 및 공개 설정
    - 지속적 업데이트 (새 커밋/성과 반영)
- **주요 처리**
    - GitHub + Notion 데이터를 종합하여 포트폴리오 데이터 생성
    - 정적/동적 포트폴리오 페이지로 렌더링 가능

#### 4.7 에이전트 자동화·스케줄링

- **기능 ID**: AGENT-001 ~ AGENT-005
- **설명**
    - 사용자/그룹별 자동화 규칙 설정
    - 주기적 실행 (매일/매주 등)
    - 이벤트 기반 실행 (새 커밋, 이슈 생성 등)
    - 에이전트 작업 로그 및 결과 저장
- **주요 처리**
    - LangGraph 워크플로우로 다단계 작업 수행
    - 실패 시 재시도 및 사용자 알림

#### 4.8 알림 및 대시보드

- **기능 ID**: NOTI-001 ~ DASH-003
- **설명**
    - 작업 완료·실패·일정 임박 알림
    - 개인/팀 대시보드 (진행률, 최근 활동, 포폴 상태)
    - 에이전트가 대신 수행한 작업 목록 표시

### 5. MVP 범위 (1차 구현 권장)

**필수 (우선순위 높음)**

- 회원가입/로그인
- GitHub + Notion 연결
- 개인용 진행상황 자동 메모
- 간단한 포트폴리오 카드 생성
- 기본 스케줄러

**2차 이후**

- 친구 추가·그룹
- 팀 프로젝트 관리
- 고도화된 에이전트 루프
- 포트폴리오 공개 페이지
